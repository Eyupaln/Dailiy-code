# Graphs — Detaylı Anlatım

## Graf Nedir?

Graf, **düğümler (nodes)** ve **kenarlar (edges)** ile bağlanan bir veri yapısıdır. Ağaçların genel hali gibi düşünebilirsin.

```
    A --- B
    |     |
    C --- D
```

- **Düğüm (node):** A, B, C, D
- **Kenar (edge):** A-B, A-C, B-D, C-D

---

## Ağaç vs Graf

| Özellik | Ağaç | Graf |
|---------|------|------|
| **Döngü** | Yok | Olabilir |
| **Kök** | Var | Yok |
| **Yapraklar** | Var | Yok |
| **Bağlantı** | Her düğüm bir üst düğüme bağlı | Her düğüm her düğüme bağlı olabilir |

**Temel fark:** Ağaçlarda **döngü yoktur**, graflarda **döngü olabilir**.

---

## Graf Türleri

### 1. Yönlü Graf (Directed Graph)

Kenarlar **yön** belirtir. A → B, B → A anlamına gelmez.

```
A → B
↓   ↓
C → D
```

### 2. Yönsüz Graf (Undirected Graph)

Kenarlar **yön** belirtmez. A-B, B-A aynı şeydir.

```
A --- B
|     |
C --- D
```

### 3. Ağırlıklı Graf (Weighted Graph)

Kenarların **ağırlığı** vardır. Örneğin mesafe, maliyet.

```
A --5-- B
|       |
3       2
|       |
C --4-- D
```

### 4. Ağırlıksız Graf (Unweighted Graph)

Kenarların ağırlığı yoktur. Sadece bağlantı vardır.

```
A --- B
|     |
C --- D
```

---

## Graf Gösterim Yöntemleri

### 1. Adjacency Matrix (İndişsel Matris)

Düğümlerin birbirine bağlı olup olmadığını **matris** ile gösterir.

```
    A  B  C  D
A   0  1  1  0
B   1  0  0  1
C   1  0  0  1
D   0  1  1  0
```

- `1` = bağlı
- `0` = bağlı değil

**Avantaj:** Hızlı erişim O(1)
**Dezavantaj:** Bellek kullanımı O(n²)

### 2. Adjacency List (İndişsel Liste)

Her düğümün **komşularını liste** olarak gösterir.

```
A: [B, C]
B: [A, D]
C: [A, D]
D: [B, C]
```

**Avantaj:** Bellek kullanımı O(n + e)
**Dezavantaj:** Erişim O(n)

---

## Graf Gezinme Algoritmaları

### 1. BFS (Breadth-First Search)

**Seviyeye seviye** ilerler. Queue kullanır.

```
    A
   / \
  B   C
 / \
D   E
```

**BFS Sırası:** A → B → C → D → E

### 2. DFS (Depth-First Search)

**Derinlik öncelikli** ilerler. Stack kullanır.

```
    A
   / \
  B   C
 / \
D   E
```

**DFS Sırası:** A → B → D → E → C

## Python'da Graf Oluşturma

### Adjacency List ile

```python
graf = {
    'A': ['B', 'C'],
    'B': ['A', 'D'],
    'C': ['A', 'D'],
    'D': ['B', 'C']
}
```

### Adjacency Matrix ile

```python
graf = [
    [0, 1, 1, 0],  # A
    [1, 0, 0, 1],  # B
    [1, 0, 0, 1],  # C
    [0, 1, 1, 0]   # D
]
```

---

## Özet

- **Graf:** Düğümler ve kenarlar ile bağlanan veri yapısı
- **Ağaç vs Graf:** Ağaçlarda döngü yok, graflarda olabilir
- **Graf türleri:** Yönlü, yönsüz, ağırlıklı, ağırlıksız
- **Gösterim:** Adjacency matrix, adjacency list
- **Gezinme:** BFS (Queue), DFS (Stack)
