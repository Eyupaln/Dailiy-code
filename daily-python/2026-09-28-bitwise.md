# Bitwise Operations — Adım Adım Anlatım

## İkili Sistem (Binary) Nedir?

Bilgisayarlar sayıları **ikili sistemde** saklar. Yani her sayı `0` ve `1` lerden oluşur.

| Ondalık | İkili |
|---------|-------|
| 0 | 000 |
| 1 | 001 |
| 2 | 010 |
| 3 | 011 |
| 4 | 100 |
| 5 | 101 |
| 6 | 110 |
| 7 | 111 |
| 8 | 1000 |

**Önemli:** Her basamak 2'nin kuvvetini temsil edir:
- `101` = 1×2² + 0×2¹ + 1×2⁰ = 4 + 0 + 1 = **5**
- `110` = 1×2² + 1×2¹ + 0×2⁰ = 4 + 2 + 0 = **6**

---

## 6 Temel Bitwise Operatör

### 1. AND (`&`) — "İkisi de 1 ise 1"

```
5 = 101
3 = 011
---------
& = 001  → 1
```

**Kural:** Her iki bit de `1` ise sonuç `1`, aksi halde `0`.

**Örnek:** `6 & 3`
```
6 = 110
3 = 011
---------
& = 010  → 2
```

---

### 2. OR (`|`) — "En az biri 1 ise 1"

```
5 = 101
3 = 011
---------
| = 111  → 7
```

**Kural:** En az bir bit `1` ise sonuç `1`, aksi halde `0`.

**Örnek:** `4 | 2`
```
4 = 100
2 = 010
---------
| = 110  → 6
```

---

### 3. XOR (`^`) — "Farklı ise 1"

```
5 = 101
3 = 011
---------
^ = 110  → 6
```

**Kural:** İki bit **farklı** ise `1`, **aynı** ise `0`.

**Örnek:** `7 ^ 7`
```
7 = 111
7 = 111
---------
^ = 000  → 0
```

**Özel durum:** `x ^ x = 0` (her sayı kendisiyle XOR'lanınca 0 olur)

---

### 4. NOT (`~`) — "Ters çevir"

```
5 = 00000101
~5 = 11111010  → -6 (Python'da negatif sayılar ikiyle tam sayı olarak saklanır)
```

**Kural:** `0` → `1`, `1` → `0`

---

### 5. Left Shift (`<<`) — "Sola kaydır"

```
5 << 1 = 1010  → 10
```

**Kural:** `x << n` = `x * 2^n`

**Örnek:** `3 << 2`
```
3 = 011
3 << 2 = 01100  → 12
```

**Neden?** Sola kaydırma, her biti 2 ile çarpar. İki kez kaydırmak = 4 ile çarpmak.

---

### 6. Right Shift (`>>`) — "Sağa kaydır"

```
6 >> 1 = 11  → 3
```

**Kural:** `x >> n` = `x // 2^n`

**Örnek:** `8 >> 2`
```
8 = 1000
8 >> 2 = 10  → 2
```

**Neden?** Sağa kaydırma, her biti 2'ye böler. İki kez bölmek = 4'e bölmek.

---

## Özet Tablo

| Operatör | İsim | Kural | Örnek |
|----------|------|-------|-------|
| `&` | AND | İkisi de 1 ise 1 | `5 & 3 = 1` |
| `\|` | OR | En az biri 1 ise 1 | `5 \| 3 = 7` |
| `^` | XOR | Farklı ise 1 | `5 ^ 3 = 6` |
| `~` | NOT | Ters çevir | `~5 = -6` |
| `<<` | Left shift | `x * 2^n` | `5 << 1 = 10` |
| `>>` | Right shift | `x // 2^n` | `6 >> 1 = 3` |

---

## Python'da Test

```python
print(f"5 & 3 = {5 & 3}")    # 1
print(f"5 | 3 = {5 | 3}")    # 7
print(f"5 ^ 3 = {5 ^ 3}")    # 6
print(f"~5 = {~5}")          # -6
print(f"5 << 1 = {5 << 1}")  # 10
print(f"6 >> 1 = {6 >> 1}")  # 3
```

## Neden Bitwise Operatörler Önemli?

1. **Hız:** Bitwise işlemler, normal aritmetikten çok daha hızlıdır
2. **Bellek:** Verimli bellek kullanımı (flags, permissions)
3. **Algoritmalar:** Birçok algoritma bitwise kullanır (hashing, compression, graphics)
4. **Mülakatlar:** Teknik mülakatlarda sıkça sorulur
